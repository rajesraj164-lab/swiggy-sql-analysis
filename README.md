**Swiggy Restaurant Analysis**

**Project Overview**

This project analyzes Swiggy restaurant data to understand restaurant trends, customer ratings, cuisines, pricing, and city-wise performance.

The analysis was performed using SQL to extract meaningful business insights from the dataset.

**Project Objectives**

The main objectives of this project are:

Analyze the number of restaurants across different cities

Identify the most popular cuisines

Find restaurant chains with the highest number of branches

Compare average restaurant ratings across cities

Analyze the average cost for two across cities

Identify cuisines with the highest average ratings

Find highly rated restaurants with a large number of ratings

Identify cities offering better value based on rating and cost

**Tools & Technologies**

SQL
Excel – Data preparation.

**Business Questions**

The project answers the following business questions:

How many restaurants are listed per city?

What are the most popular cuisines across India?

Which restaurant chains have the most branches?

Which cities have the highest average restaurant ratings?

What is the average cost for two across cities?

Which cuisines have the highest average ratings?

Which restaurants have ratings above 4.5 and more than 1,000 ratings?

Which cities provide better value based on restaurant rating and cost?
